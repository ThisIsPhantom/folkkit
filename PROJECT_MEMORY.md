# Folkkit Project Memory

## Durable decisions

- 2026-08-31: Folkkit was approved as the independent product name. Preliminary RDAP checks showed `folkkit.ch` and `folkkit.com` as unregistered at that time; neither domain was purchased and no trademark clearance was completed.
- 2026-08-31: The private repository `ThisIsPhantom/folkkit` preserves the full history of `MercuriusDream/convert-everything`; inherited base commit: `0d4b61ed89963e6ffab505d0ead757c5fa2f4a64`.
- 2026-08-31: Folkkit remains AGPL-3.0-only. Public deployment must expose the corresponding source for the exact deployed version and preserve upstream and third-party notices.
- 2026-08-31: Version 1 is free and accountless, with no payment flow, backend, database, cloud storage, analytics, advertising, or telemetry.
- 2026-08-31: Files are processed locally. Runtime assets are self-hosted; inherited Google Fonts and the external FFmpeg CDN must be removed before release.
- 2026-08-31: The interface is German/English and responsive. Primary entry points are PDF, QR, and conversion, with a separate advanced catalog.
- 2026-08-31: Content history is off by default and may be enabled only by explicit local opt-in.
- 2026-08-31: The approved visual direction is `Warm Shell / Dark Workbench`, without violet-blue AI glow, neon, or generic AI decoration.
- 2026-08-31: Hosttech is the intended static host. `main` is full source and `plesk` must be generated as hosting-only. No live deployment is authorized or performed.
