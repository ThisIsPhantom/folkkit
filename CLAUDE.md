# Folkkit

Follow `AGENTS.md`, `CONTEXT.md`, `PROJECT_MEMORY.md`, and the approved Folkkit design specification before changing code.

The stack remains Vite, React, and plain CSS. The approved Studio extension in `docs/superpowers/plans/2026-09-05-folkkit-studio.md` replaces the old visual direction with a modern light Tool Studio, graphite, restrained accents, compact sans-serif typography, and optional dark mode. Do not add decorative glow, neon, or generic AI ornament. Fonts and runtime assets must be self-hosted.
