# Folkkit

Follow `AGENTS.md`, `CONTEXT.md`, `PROJECT_MEMORY.md`, and the approved Folkkit design specification before changing code.

The inherited stack remains Vite, React, and plain CSS unless an approved implementation plan changes it. Folkkit's approved design is `Warm Shell / Dark Workbench`: warm and human outer surfaces, a focused dark work area, and no purple, blue AI glow, neon gradients, floating orbs, or generic AI decoration. Fonts and runtime assets must be self-hosted.
